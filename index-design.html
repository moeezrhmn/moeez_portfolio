Multi-channel catalogue sync

Problem

Catalogue and stock maintained by hand in two storefronts. Drift caused oversells; updates ate a full working day each week.

Approach

Laravel sync engine over both REST APIs — webhook-driven deltas, queued reconciliation batches, idempotent writes and a replayable failure log.

03 2024 — 2025

Order-to-dispatch automation

UK e-commerce retailer · via Maxenius

Problem

Every order was re-keyed into the courier portal by hand. Address typos became returned parcels and refunds.

Approach

Event-driven pipeline: order webhook → validation → Royal Mail label generation → tracking write-back, with retries and a dead-letter queue for exceptions.

40+ orders a day dispatched with no human in the loop. Ops touch only the exception queue.

Laravel · Queue workers · Royal Mail API · MySQL
